# Security Policy

## Supported Versions

Security updates are provided for the latest released version of this module.

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅         |
| Older releases | ❌         |

If you are using an older version, please upgrade to the latest release before reporting a security issue whenever possible.

## Reporting a Vulnerability

If you discover a security vulnerability in this module, **please do not create a public GitHub issue**.

Instead, please report the vulnerability privately using **GitHub's private vulnerability reporting** feature:

**Security → Report a vulnerability**

Please include as much information as possible, for example:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected module version
* The affected Magento version
* The potential impact
* A proof of concept, if available

I will review the report and, where appropriate, work on a fix and release an updated version.

## Response

Security reports will be reviewed as soon as reasonably possible.

If the vulnerability is confirmed, I will work on a fix and publish it in a new release. Depending on the severity of the issue, additional information may be provided in the release notes or GitHub Security Advisories.

Thank you for helping to keep this project secure.
